---
title: "Build a slideshow"
description: "Edit slides, speaker notes, fragment reveals, branches, and hotspots."
---

Slideshow projects are navigable presentations rather than ordinary linear videos.

The **Slideshow** tab appears in the right panel when the active composition contains a slideshow. Use it to manage:

- slides;
- speaker notes;
- fragment reveals;
- how long a fragment holds;
- branches to different slides;
- clickable hotspots.

## Build the basic path first

Create a clear beginning-to-end presentation before adding branches. Confirm that normal next and previous navigation works and that every slide has a meaningful role.

## Add fragment reveals

Fragments reveal content within a slide. Use them to control attention, not to make every bullet animate separately.

Check the hold time when a slideshow may also be played or rendered automatically.

## Add branches and hotspots

Use branches when the viewer genuinely needs a different path. Add hotspots to the visible object that represents the choice, then test every destination and return path.

Keep a way forward from every branch. A beautiful slide that traps the viewer is still broken navigation.

Use the `/slideshow` agent workflow when you want help planning and building the full deck.
