---
title: "Use layers and groups"
description: "Find overlapping elements, control stacking order, and organize related items."
---

Click **Inspector**, then open **Layers** for a structured view of the elements in the current composition.

Use it when something is hidden, difficult to click, outside the frame, or part of a group.

## Select from Layers

Click a layer to select the matching element on the canvas and timeline.

The selection stays connected across Studio: choosing an item in one area helps you locate it in the others.

## Control what appears on top

Stacking order controls which visual covers another when they overlap. Move an element forward or backward when the wrong item is covering it.

Timeline tracks organize timing; they are not automatically the same as visual stacking order.

## Group elements

Group items that should move and stay organized as one unit. You can later open or ungroup them when you need to edit the individual children.

## Nested compositions

A nested composition is a reusable scene inside another composition. Expand it in the timeline or open it directly, then use the breadcrumb to return to the parent.

Edit the nested composition when the change should affect that reusable scene itself. Edit the parent when you only need to change when or where the scene appears.
