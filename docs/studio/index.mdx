HyperFrames Studio is the visual workspace that opens when you preview a project.

Use it to understand what an agent built, make direct changes, and export the finished result. The edits stay with the project, so the visual editor, source files, and final render are working on the same composition.

## Open Studio

From a HyperFrames project folder, run:

```bash
npx hyperframes preview
```

Your browser opens the project in Studio. Keep the terminal process running while you work.

## Two ways to look at a project

Use **Storyboard** when you are reviewing the idea and the planned sequence.

Use **Preview** when you are editing the built video: canvas, Inspector, timeline, Code, Comps, Assets, Catalog, Variables, and Renders.

Switching views does not create a different project. It changes what you are focusing on.

## Studio and your agent work together

Studio is best for direct, visible changes. The agent is best for changes that require broader reasoning or source work.

| Change | Good place to start |
| --- | --- |
| Move a title or adjust its color | Studio |
| Trim a clip or split it at the playhead | Studio |
| Make the opening explain the product sooner | Agent |
| Add a completely new scene with new media | Agent |
| Fix a lint issue you do not understand | Copy it to the agent from Studio |
| Export a vertical and landscape version | Studio or agent, depending on whether the layout must change |

<Tip>
  If you can point at the thing you want to change, try Studio. If you need to describe a new outcome, ask the agent.
</Tip>
