title: "Export and share"
description: "Choose a format, render a finished file, or publish a project for review."
---

For most finished videos, export an MP4 at the project’s original resolution. Choose another format only when the next tool or platform requires it.

| Need | Good starting choice |
| --- | --- |
| Upload or share a normal finished video | MP4 |
| Keep transparency for an overlay | WebM or MOV with a compatible alpha workflow |
| Continue editing in another video tool | High-quality MOV or the format requested by that tool |
| Deliver a high-resolution master | 4K preset |
| Let someone review an evolving project | Publish a stable share link |

Before delivery, watch the export itself. A project can look correct at one preview moment while still containing a late caption, missing media frame, or abrupt ending elsewhere.
