The Catalog is a library of visuals you can add to a project instead of building each one from scratch.

Use a **block** when you want a larger scene or self-contained visual. Use a **component** when you want a smaller effect or behavior inside an existing scene.

## Add an item

Each catalog page shows what the item does and where it belongs. Ask your agent to add it, or use the command shown on the item page.

After adding an item:

1. Replace its example content with your real content.
2. Match the colors and type to your project.
3. Check timing in the complete video, not only in isolation.
4. Keep the parts that serve the story; remove decorative motion that does not.

<Note>
  Catalog items are starting points. A good result usually needs content, timing, and styling changes to feel native to your project.
</Note>
