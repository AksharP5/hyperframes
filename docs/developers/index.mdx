## Start with the smallest surface

- Use the **CLI** for normal project and render automation.
- Use the **SDK** when your application needs to inspect or edit compositions.
- Use the **Player** when you need embedded playback.
- Install individual **packages** when you are building infrastructure or a custom product surface.
- Read the raw **schema** when generating or validating composition source.

Most applications do not need to depend on every package.
