HyperFrames is a way to create videos with an AI agent and still keep full control over the result.

Tell your agent what you want to make. It can plan the story, gather media, build the scenes, add motion, and open the project in **HyperFrames Studio**. In Studio, you can watch the video, rearrange timing, edit text and design, adjust animation, and export the finished file.

You do not need to understand the rendering engine or write HTML to get started.

## How the pieces fit together

<Steps>
  <Step title="You describe the result">
    Give an agent a product link, a script, a piece of footage, a pull request, a song, or a plain-language idea.
  </Step>
  <Step title="The agent builds a project">
    The agent chooses the matching HyperFrames workflow, confirms the important creative choices, and creates the scenes and media.
  </Step>
  <Step title="You review it in Studio">
    Play the result, leave direction, edit visible elements, change timing, adjust animation, and check the final frame.
  </Step>
  <Step title="You export or share it">
    Render a standard video, a transparent overlay, a high-resolution file, or a shareable published project.
  </Step>
</Steps>

<Note>
  HyperFrames projects are stored as normal files rather than a locked proprietary project format. That matters to agents and developers, but you can use the visual Studio without working directly with those files.
</Note>

## Choose the shortest path

- If you have an idea or source material, start with [Make your first video](/quickstart).
- If you want to explore first, open the [browser Playground](https://www.hyperframes.dev/).
- If an agent already created a project for you, open [Studio](/studio).
- If you want a ready-made visual, browse the [Catalog](/catalog).
- If you are integrating HyperFrames into another product, go to [Developers](/developers).
